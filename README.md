# DataGenie Prospect Lab (Milestone 5)

A single-file app (`index.html`). No build step, no server, no data leaves the browser.

**Run:** open `index.html`, or publish with GitHub Pages (Settings → Pages → deploy from `main`).

**What it does:** pick a prospect (five, with four-test scores and a verdict); hunt for a problem the hard way (filters, a clock, a slice counter; the problem only shows on the right route AND the hourly view); run a real sweep over the demo dataset; read the Top Story it builds; turn it into a Brief. A guided demo (▶) steps through it for screen recording.

**Honest limits:** all data is synthetic and seeded. Only Marks & Spencer has a dataset. The sweep is real but small (its count is shown); production estates reach 100,000+ combinations. Slack, PDF and "send to owners" are simulated. See assumptions in step 5 (also behind every "?").
